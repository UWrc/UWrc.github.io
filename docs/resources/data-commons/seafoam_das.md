## What is this?

The SeaFOAM DAS dataset contains distributed acoustic sensing (DAS) measurements collected using a submarine fiber-optic cable in Monterey Bay, California. Permission has been granted by the data provider to download the dataset for research purposes.

The requested subset covers October 1–10, 2026 (UTC), with a total volume of approximately 3.7 TB.

Publication date: To be confirmed.

License and redistribution permissions: To be confirmed with the data provider.

## What will it be used for?

This dataset will support initial testing and evaluation of computational methods for processing large-scale submarine DAS measurements at UW, with potential applications in passive interferometry, ocean acoustics, and seismic signal processing.

## How to prepare for use?

The dataset is stored in HDF5 format, with approximately one file per minute and files organized into separate directories for each day. The data contain 10,300 channels sampled at 200 Hz.

Python libraries such as NumPy and h5py can be used to process the data.

Access to the original dataset is coordinated with the data provider.

## How to access?

Once approved and transferred to Hyak, the dataset will be temporarily stored for initial research testing.

The storage location, access conditions, and availability period will be confirmed by UW Research Computing.

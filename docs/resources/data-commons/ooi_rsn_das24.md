## What is this?

The OOI RSN DAS24 dataset is a publicly available Distributed Acoustic Sensing (DAS) dataset provided by the Ocean Observatories Initiative (OOI) Regional Cabled Array (RCA). It contains fiber-optic DAS measurements that can be used for research in seismology, ocean acoustics, distributed sensing, interferometry, and signal processing.

The dataset is publicly available at:

https://github.com/uwfiberlab/OOI_DAS_2024

The total dataset size is approximately 2.4 TB.

## What will it be used for?

This dataset will be used to support research at the University of Washington on distributed acoustic sensing (DAS), passive interferometry, ocean acoustics, and seismic signal processing.

## How to prepare for use?

Download the dataset from the public OOI DAS24 repository:

http://piweb.ooirsn.uw.edu/das24/data/

No registration or authentication is required.

## How to access?

Once hosted in Hyak Data Commons, the dataset will be available on Hyak Klone at /data/das24.

## How to cite?

Please cite the Ocean Observatories Initiative (OOI) Regional Cabled Array (RCA) DAS24 dataset according to the OOI data citation guidance.
